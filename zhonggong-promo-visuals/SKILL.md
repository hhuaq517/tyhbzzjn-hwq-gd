# 中公推广图视觉产线（完整资源包）

本技能合并「中公教育方形产品推广海报」与「中公推广图产线」两份规范。先按成品类型选择对应路径：方形课程产品海报使用包内 `scripts/poster.py` 配置生成；小红书封面、直播装饰、通用推广图与考情一页纸使用 HTML/CSS → Chromium → 分层 PSD 路径。两类产物的尺寸、元素和 PSD 实现分别适用，不要混用。

技能包内已附带执行脚本（`scripts/`）、中公 Logo、小鹿 Lulu 造型与字体参考图（`assets/`），以及 Python 依赖清单（`requirements.txt`）。字体二进制未打包：字体授权/再分发范围无法从文件本身验证，运行时需在本机安装白名单内且已获授权的字体。Playwright 所需 Chromium 也需按运行环境单独安装。

# 中公教育方形推广海报生成

纯代码（Python + Pillow + NumPy + 内置 RLE PSD 写入器）生成方形高清推广海报，不调用 Photoshop。
本技能沉淀了广东中公设计师的交付标准、合规红线与设计系统。

## 何时使用
用户要求做中公教育的产品推广海报 / 方形宣传图 / 课件推广图，或提交「公告名词 + 课件名称 + 内容 + 拼团与单独购买定价」四要素时。

---

## 一、交付物（必须齐）
固定 3 个产物，放进**新建的独立文件夹**：
1. 方形高清 JPG —— **有二维码版**
2. 方形高清 JPG —— **无二维码版**
3. 分层可编辑 **PSD**（每个元素独立图层）

⚠️ **`base_name` 一律以「活动图」结尾**（2026-09-28 定稿：所有产物都要带）。
例：`base_name` = `2027广东选调粤政萃学笔试练手课件包活动图`，实际产物为
`2027广东选调粤政萃学笔试练手课件包活动图_有二维码.jpg` /
`...活动图_无二维码.jpg` / `...活动图.psd`。
⚠️ 文件夹名**不带**「活动图」（文件夹是项目容器，以后可能装别的类型产物），
只把「活动图」后缀加在 3 个产物文件名上。

### 存放位置（硬性）
**`out_dir` 必须落在【当前工作空间】目录下**，一单一文件夹，
命名用「年份 + 地区 + 项目 + 产品名 + `-海报`」。
不要写到工作空间之外（如桌面、下载等系统目录）。
例：`<工作空间>/低价课海报生成/2026珠海基层服务岗字字珠机笔试甄题冲刺包-海报/`

⚠️ **文件夹名一律以 `-海报` 结尾**（2026-10-21 定稿）。
理由：同一个项目以后可能还会装考情手册、PPT 等别的类型产物，带类型后缀一眼能分辨这一格是什么；
也与「活动图」后缀的文件名形成「文件夹=海报 / 文件=活动图」的分层对应。
写法固定为**半角连字符 + `海报`**，即 `-海报`；不要写成 `-海报图`、`（海报）`、`_海报`、`海报`。

尺寸默认 `2000×2000`，JPG 用 `quality=95, subsampling=0`。
一次性脚本、临时预览图、虚拟环境等辅助文件在完成后**必须清除**，只留产物。

## 二、硬性红线（逐条自检，不可违反）
1. **必带中公教育 logo**（包内 `assets/brand/zhonggong-logo.png`）。
2. **字体必须在白名单内**（见第四节），不得使用未明确版权的字体。
3. **必须说明课件均为电子版**（如「电子课件」标签 + 卡片内文字说明）。
4. **底部小字、低饱和度**写明课件**全称**。
5. **全图禁止出现「资料」二字**，一律用「课件」替代。
6. **规避违规广告词**（见第五节词库），用同义词替代。
7. **禁用未明确版权的素材/图形**；需要图形元素时用代码**绘制原创矢量图形**。
8. **不调用 Photoshop**，全部在代码层解决。
9. 产品文案不出现「资料」以外的政治/医疗等敏感表述；冲刺卷≠真题。
10. **公告名不得出现党政机关全称**（如「中共XX省委组织部」「XX市人民政府」）——
    一律写成「地区 + 年度 + 事项 + 公告」（如「广东省2027年度选调优秀大学毕业生公告」）。
    ⚠️ 这条是 2026-09-28 明确要求：带机关名「太违规了」，即使名称完全属实也不要写。

### 二维码规则
- **有二维码版**：右下留出**空白方框**（虚线描边，内含引导线），框下写「**码上获取**」；价格同时展示「X人拼团 …元」与「单独购买 …元」。
- **无二维码版**：**取消拼团表述**，价格改写「**仅售 …元**」为唯一价格，并**删除单独购买价**。
- 如材料为**真题类**，需另加小字备注「考生回忆仅供参考」（非真题不加）。

## 三、设计系统（版式与风格）

### 版式层级（自上而下）
1. 顶部：logo（白色圆角底衬托，保证深底可读）
2. 顶部右侧：**项目标签**（=`project_tag`，如「事业单位」「教师招聘」）
   - ⚠️ **不要写「XX分部/地区分部」**（属画蛇添足）；此位置永远放项目类型
3. 公告名词（居中、浅色小字）
4. ~~金色小标 kicker~~ —— **已删除，永远不要再加**（如「2026 广东 · 事业单位笔试备考」这类小字一律不要）
5. **主标题**（大号，公式：地区+项目+笔试/面试+冲刺卷/题/无+课件包）
   - ⚠️ **主标题一律用「地区 + 项目」**（如「广东选调」「海珠事编」），
     **产品品牌名（如「粤政萃学」「粤正登科」）不进主标题**，只出现在底部课件全称小字里
     （2026-09-28 定稿：「大标题还是要以公告为主」）。
   - **两端对齐到内容框宽度**（`title_width` = 卡片宽度 1600，字号不变，字距自动反算放宽）
   - 两行都要与下方课件内容卡片左右边缘对齐，页面更饱满
6. 副标题亮黄标（如「全真模拟 · 三套」）+「电子课件」青框标，**两个标签并排居中**
7. 课件内容卡片（白底、粗黄边、勾选列表、右上「共 N 份电子文档」、底部电子版说明）
   - **详情板块要撑满**：每行用**课件全称**（参考原始文件命名，如
     「2026海珠区事业单位招聘高校毕业生冲刺卷（一）」），名称**左对齐**、
     后缀说明（如「· 参考答案及解析」）**右对齐**，字体自适应缩放，撑满卡片不溢出
   - 底部说明文字不要太小（≥38）
8. 价格区
9. 领取说明：`购买后在中公教育 App 可下载电子文档`
10. 底部课件全称小字（低饱和）

### 美术规范
- **扁平化，禁止阴影/浮雕/发光堆叠**（此前教训：阴影过多导致画面杂乱、图层不协调）。
- **活力撞色**（低饱和太"闷"也不好，用有活力的强对比撞色）：
  宝蓝底 + 珊瑚橙 + 亮黄 + 电光青，四种颜色互相撞击但有主次。
  参考值：底 `#122060→#224AB2`、白 `#FFF`、浅 `#C6D6FF`、次要 `#9CAEE2`、
  强调色（珊瑚橙）`#FA6C4A`、亮黄 `#FFCD3D`、青 `#3DD6E8`、卡片文字墨蓝 `#1A245C`。
  ⚠️ **不要用纯正红 `#FF0000/#FF3B3B`**——在宝蓝底上太突兀刺眼，用珊瑚橙过渡。
- **主次分明**：核心标题/价格/冲刺卷关键字用珊瑚橙，副标题用亮黄底+墨蓝字，辅助标签用青。
- **地域/项目元素**：每个新产品按地区特性提取元素，用代码绘制原创矢量（如广州塔线稿 + 珠江水纹 + 琶洲几何；珠海用日月贝双壳 + 港珠澳大桥斜拉索）。**每次风格必须有区别**，不要千篇一律。
  ⚠️ 元素要落在**卡片上沿（`card0`）以上**的空档里，否则会被白卡片整块盖住——画完务必目检确认能看见。
- 图形元素透明度控制在 0.1–0.25 之间，做背景纹理，不与前景争抢。

### 字体规范（只可用下列已安装字体）
| 用途 | 字体 | 文件 |
|---|---|---|
| **大标题（稳重，首选）** | 方正兰亭粗黑 | `FZLTCHJW.TTF` |
| 大标题备选（加粗宋体） | 方正特雅宋 | `FZTYSJW.ttf` |
| 大标题备选（更重） | 方正兰亭特黑 / 方正粗谭黑 | `FZLTTHJW.TTF` / `FZCTHJW.TTF` |
| 次级/小标题 | 方正兰亭粗黑 | `FZLTCHJW.TTF` |
| 正文 | 方正兰亭黑 | `FZLTHJW.TTF` |
| 备选黑/标题 | 站酷高端黑 / 站酷酷黑 / 庞门正道标题体 | `站酷高端黑修订版1.13.ttf` / `站酷酷黑.ttf` / `庞门正道标题体2.0增强版.ttf` |

> **大标题必须稳重**：用方正兰亭**粗黑**（B 字重）。
> ⚠️ **不要用特黑/超粗**——笔画会粘连，字口糊成一团；太粗反而显廉价。

## 四、工作流
1. **收集四要素**：公告名词 / 课件名称 / 内容截图或文字 / 拼团价与单独价。
2. **澄清**：有疑问先反问（尺寸、二维码处理、大标题文案、地域元素方向、真题与否、底部全称）；把把握提到 95% 再动手。
3. **读公告**（若给链接）：提取报名时间、笔试时间/内容、招聘人数，作为海报可用的信息点。
4. **改配置**：编辑 `poster.py` 顶部 `CONFIG`（或用 `--config cfg.json` 覆盖）。
5. **生成**：见第八节的命令（不要用系统 `python3`，本机缺依赖）。
6. **自检**：运行输出会打印文案合规检查；再读图核对版式。
7. **核对产物**：2 JPG + 1 PSD，目录只留产物；**删除脚本临时件与虚拟环境**。
8. 若用户提出修改，回到第 4 步改 CONFIG 重生成。

## 五、文案合规词库（自动检查 + 人工复核）
**禁用（命中即改）**：资料、真题、押题、上岸、保过、包过、协议班、绝密、内部、命题、
命中、预测、必过、保分、官方指定、第一、最好/最佳/最强、100%、百分百、泄题、原题。

**合规替代**：资料→课件；真题→历年试题；押题→冲刺卷/模拟卷；上岸→成功入围/考入。

> ⚠️ **「第一」的误报排除（2026-10-08，2026-10-23 扩充）**：公告名里的「第一批 / 第二批 / 第三批」是招考**批次**用词，
> 课件条目的「第一套 / 第二套 / 第三套」是**套数编号**，都不是广告法的绝对化用语。
> `check_copy()` 扫「第一」前会先用 `re.sub(r"第[一二三四五六七八九十](批|套)","",t)`
> 剔除「第N批 / 第N套」，避免误报。除此之外的「第一」仍照常拦截。

## 六、poster.py 使用
路径：`scripts/poster.py`

- Python 依赖见包内 `requirements.txt`；方形海报 PSD 使用同目录的 `psd_rle.py`（RLE 写入），不要改用 pytoshop —— 原因见 6.1。
- 默认 Logo 路径指向包内 `assets/brand/zhonggong-logo.png`；默认输出目录位于启动命令时的当前目录，运行前应从当前工作空间根目录启动，并按项目修改目录名。
- `CONFIG` 字段：
  `out_dir, base_name, size, logo_path, project_tag, notice, notice_size, title_main,
   title_sub[[文本,"w|r"]], title_main_size, title_sub_size, title_width,
   subtitle, badge, content_title, content_meta, content_rows[[全称,后缀]],
   content_note, layout{}, price_group, price_group_color, price_value, price_single,
   price_strike, only_price, only_sub,
   claim, footer, motif, palette{...}`
- **无 kicker 字段**（已永久移除）。
- `notice` **字号自适应 + 两侧对称装饰线**：长公告名（省市级公文）自动缩到不溢出；
  `notice_size` 只设上限（默认 **52**）。公告名偏短（如「XX招聘公告」13 字）时，
  文字两侧会自动补一对细线 + 端点圆点，把整行撑成饱满的「信息条」——
  端点正好落在页边距 96 / 1904，与顶部细线左右对齐（名字太长留不下线时自动跳过）。
  ⚠️ 公告名一短（20 字左右）装饰线就会顶到 `deco_max`（400），此时两端仍能对齐页边距；
  若把 `deco_max` 调小，短线就撑不到边、整行会显松，改前先算一遍。
  公告名一律写成「地区 + 年度 + 事项 + 公告」的规范表述，**不得带发文机关全称**（见第二节红线 10），
  公文外壳（「关于印发…的通知」）也一并去掉。
  例：「广东省人民政府印发《广东省全民科学素质行动规划纲要实施方案（2026—2030年）》」
  → 精简为「广东省全民科学素质行动规划纲要实施方案（2026—2030年）」。
- `layout`：单项目微调 `LAYOUT` 的任意键（如 `{"rows_top": 200}`）。
  ⚠️ **3 条内容走默认版式时**，`rows_top` 默认 216 会让第 3 行与 `content_note` 净间距只剩 13px，
  调成 **200** 可拉开到 29px。改完必须目检。
- **免费 / 0 元场景**：`price_group` 写「限时免费」并把 `price_group_color` 设为 `"yellow"`（默认 `light` 太弱）；
  `price_value` 写 `"0"`；`price_single` 改成领取引导语（如「扫码即领 · 全套电子课件」）并设
  `price_strike: false` 关掉删除线；`only_price` 写 `"0"`，`claim` 改「**领取**后在中公教育 App 可下载电子文档」。

### ⚠️ `textbbox` 算出的间距 ≠ 视觉间距（2026-10-14 实测教训）
用 `ImageDraw.textbbox` 反算净距会**严重高估留白**：
`notice_y 288 / title_y1 430`（差 142）时 bbox 算出净距还有 0.5px，实图**完全贴死**；
`title_y1 430 / title_y2 646`（差 216）时实图两行**几乎相接**。
实测需要 **notice 与 title1 差 ≈180**、**title1 与 title2 差 ≈255** 才有舒服的视觉间隙。
根因：中文方块字 bbox 含 ascent/descent 留白，`text_img` 按 bbox 高建图，
而 `tracked_segs` 把**图几何中心**对齐到 y 坐标，实际墨迹并不在图的几何中心。
**→ 估完间距一律出图目检，别信 bbox 算术。**
另：标题两端对齐后墨迹实测**左边界 197 / 右边界 1803**（含 3px 描边），

### 6.1 PSD 生成（psd_rle.py）—— 为什么不能用 pytoshop

2026-09-20 试用反馈「本机 Photoshop 打不开产物 PSD，提示文件与这个版本的 Photoshop 不兼容」。
逐字节诊断出两个不合规点：

1. **压缩方式错误（主因）**：pytoshop 用 ZIP 压缩写 PSD(version 1) 的 ImageData 与图层通道。
   而 PSD 的压缩只允许 **Raw(0) / RLE(1)**，ZIP(2/3) 属 PSB(version 2) 特性 → Photoshop 直接判不兼容。
2. **图层名长度算错**：pytoshop 写 Pascal 字符串时把 padding 计入了长度字段，
   psd-tools 读出来的图层名尾部带 `\x00`。

修复：自己写了 `psd_rle.py`，只做「把一组同尺寸 RGBA 图层写成分层 PSD」这一件事：
- 压缩统一用 **RLE (PackBits)**，行字节数表按**通道优先**排列（与 Photoshop / psd-tools 一致）
- 图层自动裁剪到非透明包围盒，`top/left/bottom/right` 如实记录
- 图层名同时写 Pascal(UTF-8) 与 `'luni'` Unicode 块；extra data 补到偶数
- Image Resources 写入 ResolutionInfo(1005)

实测（2026-09-20，2000×2000 / 14 图层）：**2.8 MB，生成耗时 1.8 秒**。

**自检方法**（无法调用 Photoshop 时的替代验证）：
```python
psd = PSDImage.open(path); psd.composite()   # psd-tools 应能完整读回
```
把合成结果与交付 JPG 比对，差异应恰好等于「同一张图 JPG 往返噪声」的量级
（quality=95 时约 0.59 平均差、12% 像素 >2）——**若明显更大，说明图层数据有问题**。
另可用 `open -a "Adobe Photoshop 2025" <file>` 请人工确认。

# 中公推广图产线

产线定位：出**推广图**（JPG + 可编辑 PSD），不是资料 PDF。全部在代码层完成，不调用 PS。

## 硬性规范（不可违反）

1. **产物**：高清 JPG + 可编辑 PSD，一单一文件夹，命名 `年份+地区+项目+产品名`。中间工具/临时文件用完即清，交付文件夹里只留最终件。
2. **必带元素**：中公教育 logo + 小鹿 lulu 形象。素材随包提供：`assets/brand/zhonggong-logo.png`、`assets/lulu/`（15 个造型，带透明通道）。
3. **字体白名单**：按包内 `assets/font-reference.jpg` 清单使用（方正 / 站酷 / 庞门正道 / 胡晓波 / 美瑶 / 锐字 / ZCOOL 系列）。字体文件本身不随包分发，需在运行设备安装并确认授权；禁用来路不明的字体与素材；图形一律矢量自绘（CSS/SVG）。
4. **合规词**：自动规避 真题 / 押题 / 上岸 / 保过 / 包过 / 最 / 第一 / 100% 等，替换为 历年试题 / 冲刺卷 / 成公 / 系统备考。
5. **版式层级**：logo → 公告名词 → 大标题（≤10 字）→ 补充说明（可选）→ 二维码位（有码留空框标「码上获取」，无码则优化排版）。重点内容加粗或标红。
6. **每单风格必须有区别**：按项目/平台特性提取元素。参考往期海报只提取重点，不固化格式。
7. **不擅自加内容**：用户说"内容不变"就是一字不动。

## 尺寸规范

| 类型 | 比例 | 设计坐标 | 出图 |
|---|---|---|---|
| 小红书封面（推广海报） | 3:4 | 540×720 | dsf=2 → 1080×1440，四周 ≥60px 安全边距 |
| 公众号图文首图 | 2.35:1 | 900×383 | dsf=2 → 1800×766，横版左文案/右形象分栏 |
| 直播封面 | 3:4 | 540×720 | dsf=2 → 1080×1440 |
| 竖屏直播贴图 | 9:16 | 540×960 | dsf=2 → 1080×1920，**中间整块透明**（边框式：上下信息条+角标） |
| 横屏直播贴图 | 16:9 | 960×540 | dsf=2 → 1920×1080，中间透明；居中按左右信息框空档的中心算 |
| 考情一页纸 | 长图 | 宽 1280 | dsf=2 → 2560 宽，高度自适应 |

## 三条产线

### A. 产品推广海报（小红书 3:4）
每单新建 build 文件写 HTML/CSS（`.layer` 元素 + `data-layer` 名 + `LAYER_KEYS`/`LAYER_NAMES` 定义图层顺序与中文名）。

### B. 直播间装饰三件套
封面 + 竖贴 + 横贴，一单一个文件夹（`年份+项目+直播装饰（场次）`，内含 `XX国考-<场次>-直播封面/竖屏贴图/横屏贴图` 的 jpg + psd）。视觉体系：中公蓝（#0E6BE0→#063C8E）+ 黄（#FFE24A/#FFC400）放射光芒；同系列靠**强调色 + 背景纹理 + 主题图形**区分场次，不做大改版。竖/横贴透明区：合成 JPG 用 `omit_background=False`（白底），分层 PNG 用 `omit_background=True`（保透明）。

### C. 考情一页纸（长图信息图）
信息密度高，走 HTML `<table>` 排版，追求清晰 + 权威感，不追求风格差异。骨架：logo 顶栏 → 深绿渐变标题栏（方正兰亭粗黑简体，别用特黑档）→ 浅绿副标题条（`｜` 分隔、关键数字标红）→ 三列表格（rowspan 竖排大分组标签）→ 底部补充说明条。配色：深墨绿 #0C5A38 主 + #F2F9F5 浅底 + #C62828 强调红。分层：给 body 加 `no-text` / `no-bg` class 分别整页截图 → 背景层 + 文字层（透明底）。

## 渲染管线（本 skill 附带脚本）

```bash
# 1) HTML → 合成 JPG + 分层 PNG（自动等 fonts.ready，逐层隔离截图）
python3 scripts/render_layers.py <page.html> --out <out_dir> \
  --width 540 --height 720 --dsf 2 [--full-page] [--jpg "成品名.jpg"]

# 2) 分层 PNG → PSD（自带 packbits 补丁 + 防全黑合成图修复）
python3 scripts/psd_from_layers.py --out <成品.psd> --flat <合成图.png> \
  --layer "01-背景:out/page_layers/bg.png" --layer "02-文字:out/page_layers/text.png"
```

- `render_layers.py`：`.layer[data-layer]` 元素自动识别为图层；`--full-page` 用于考情一页纸这类高度自适应页面；输出末尾打印各层覆盖率%，出现重复层会告警（说明某层截图没隔离干净）。
- `psd_from_layers.py`：`--layer` 按从下到上的顺序重复传入；`--flat` 必传（嵌入合成图，否则 PS/访达缩略图全黑）。
- Python 依赖：playwright、Pillow、numpy、pytoshop。缺则先装。

## 已知坑（必读）

- **pytoshop PSD 全黑**：必须 `psd.image_data = core.ImageData(arr)`，`arr` 形状为 `(3,H,W)`（脚本已内置处理）。
- **pytoshop packbits**：自带的 packbits 是未编译 .pyx 会挂，脚本已内置纯 Python RLE 顶替；channels 与 compression 不能同时传给 Image()。
- **lulu PNG**：PIL 直读报 `Too much memory used in text chunks`，先 `sips -Z 1400` 过一遍再用。
- **深色底大标题别用特黑档**（方正兰亭特黑）：笔画粘连发糊。用「方正兰亭粗黑简体」+ 字距 + 轻阴影 `0 1px 3px rgba(0,0,0,.12)`。
- **沙箱 mkdir**：`Path.mkdir(exist_ok=True)` 对已存在目录可能抛错，先 `if not p.is_dir(): p.mkdir(parents=True)`。
- **Chromium 正文禁用宋体（Songti SC）**：会出字体映射乱码，用 PingFang SC；方正系走 fc 字体名正常。
- **lulu 摆位**：按高度定尺寸（同高、宽随比例），比按宽度稳。

## 交付流程

1. 设计 HTML（每单新写，风格区别于上一单）。
2. 渲染 JPG + 分层 PNG → PSD。
3. **目检**：逐张看过成图——文字压边、层错位、字体糊，机器查不出来眼睛能。
4. 交付件搬进工作空间根目录「一单文件夹」，中间产物（out/、临时 HTML、处理过的素材副本）清掉（走废纸篓）。
5. 判断标准：用户在根目录 `ls` 一眼能看到这一单。
